Botplate

Botplate is an Discord bot that (poorly, I say) simulates an economy inside a Discord server.

Users can create business, buy and sell goods, earn "TuxBux", Invest in stock, pay tax, get married, go to jail. All the fun stuff.

The original Python codebase for it is so embarassingly horrible I've chose to rewrite it in Rust. Once that is finished, I plan to upload it to my GitHub.
